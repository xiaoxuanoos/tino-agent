# Tino Agent

Tino Agent 是独立维护的桌面与后端 AI Agent 项目。这个公开仓库目前处于**开发预览**阶段；首个 Tino 安装包、公开登录服务和云端部署均尚未发布。请不要把仓库中的原有安装脚本当作 Tino 的正式安装入口。

项目基于 [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) 的 MIT 许可代码开发，保留原项目的版权和 [LICENSE](LICENSE)。Tino Agent 不是 Nous Research 的官方产品。我们会逐步将用户界面、模型接入、账号体系、发布和升级流程迁移到独立的 Tino 实现；内部 `HERMES_*` 接口在迁移期间暂时保留，以避免破坏既有运行逻辑。

## 当前状态

- 已建立独立公开仓库与开发检出；旧项目仅作为只读上游来源。
- 自动提交、镜像发布、灰度升级代码已迁入并通过专项测试，但尚未启用自动运行。
- 尚无可供公众注册的多租户服务。现有后端的聊天、终端与模型密钥尚未按用户隔离，不能直接暴露到互联网。
- 目前没有正式的 Tino 桌面安装包，也没有启用静默自动升级。

开发和测试进度见 [Tino 自动化说明](docs/tino-automation.md)；在功能正式发布前，以 GitHub Releases 中的发行说明为准，而不是原项目的下载链接。

## 贡献与来源

欢迎在本仓库提交问题和改进。请勿把 API 密钥、账号凭据、用户数据目录或对话记录提交到 Git。原项目的许可证与贡献者署名保留；Tino 新增代码在相同许可证下发布。
